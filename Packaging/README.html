Screen Sharing Proxy

Native diagnostic alpha · Apple silicon · macOS 14+

This app automatically finds an allowed proxyd service and collects diagnostics. Traffic forwarding remains under development. This alpha does not relay Screen Sharing or change the firewall.

Install and open

  1. Drag ScreenSharingProxy.app onto Applications.
  2. Open Screen Sharing Proxy in Applications. The window opens and discovers the service automatically. Use its menu bar icon to reopen it.
  3. Start the failing Screen Sharing session. Optionally enter the remote Mac's numeric IP, then click Collect Diagnostics. Copy or save the report in the Diagnostics pane.

No Xcode or Python installation is needed. Launch at login is optional in General.

If macOS blocks the app

This alpha is ad hoc signed and not notarized. After installing it in Applications, open the included Terminal shortcut and paste the command below. It verifies the app identity and signature, removes quarantine only from that app, and opens it. Use it only for a download you trust.

(
set -eu
app='/Applications/ScreenSharingProxy.app'
test "$(/usr/libexec/PlistBuddy -c 'Print :CFBundleIdentifier' "$app/Contents/Info.plist")" = com.andotsy.screensharing-proxy
/usr/bin/codesign --verify --deep --strict "$app"
/usr/bin/codesign --display --verbose=2 "$app" 2>&1 | /usr/bin/grep -Fx 'Identifier=com.andotsy.screensharing-proxy' >/dev/null
/usr/bin/xattr -dr com.apple.quarantine "$app"
/usr/bin/open "$app"
)

Privacy and integrity

Private addresses and non-system paths are redacted by default. Reports retain system executable paths, ports, process IDs and service/signing identifiers. No packet contents, passwords or process environments are collected. Saved files have owner-only permissions. Review a report before sharing it.

An unknown, blocked or ambiguous discovery is reported as such. An allow entry does not establish a forwarding API or permission from other network filters.

Release assets include SHA256SUMS for download integrity checks. The CLI is included inside the app at Contents/MacOS/screensharing-proxy-diagnose.
