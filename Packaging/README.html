Screen Sharing Proxy

Native app alpha · Apple silicon · macOS 14+

This alpha adds the Proxy tab: connect through the system Ruby relay, open Apple’s Screen Sharing, and stop the relay from the app. Performance is experimental; a working connection does not establish that the high-performance UDP path is active.

Install and connect

  1. Drag ScreenSharingProxy.app onto Applications.
  2. Open the app on the controlling Mac. Quit any existing Screen Sharing session.
  3. Enter the remote Mac’s IPv4 address in Proxy, then click Connect.
  4. Sign in in Apple’s Screen Sharing window and select High Performance when offered.
  5. Keep this app open while sharing. Click Stop Relay when finished.

The app has no ten-minute experiment cutoff. Closing its window quits and stops its owned relay. After the last TCP connection closes, the relay permits reconnection for two minutes.

Settings contains optional TCP and UDP port settings. The defaults are suitable for a normally configured remote Mac. No firewall, interface, route or display settings are changed.

The transport display distinguishes TCP-only traffic from TCP and UDP. A TCP-only connection may be slower. Counters show socket submissions, not verified video decoding or input delivery. The restricted viewer’s network rules have not yet been validated.

Reports

Save Session Report… exports transport counters and fixed error labels as JSON. For system evidence, open Diagnostics and click Collect Diagnostics. Choose where to save the ZIP; cancelling preserves it for Save ZIP Again….

No Xcode, Python or gems are needed. The app uses macOS’s system Ruby.

If macOS blocks the app

This alpha is ad hoc signed and not notarized. After installing it in Applications, open the included Terminal shortcut and paste the command below. It verifies the app identity and signature, removes quarantine only from that app, and opens it. Use it only for a download you trust.

(
set -eu
app='/Applications/ScreenSharingProxy.app'
test "$(/usr/libexec/PlistBuddy -c 'Print :CFBundleIdentifier' "$app/Contents/Info.plist")" = com.andotsy.screensharing-proxy
/usr/bin/codesign --verify --deep --strict "$app"
/usr/bin/codesign --display --verbose=2 "$app" 2>&1 | /usr/bin/grep -Fx 'Identifier=com.andotsy.screensharing-proxy' >/dev/null
/usr/bin/xattr -dr com.apple.quarantine "$app"
/usr/bin/open "$app"
)

Privacy and integrity

Private addresses and non-system paths are redacted by default. Reports retain system executable paths, ports, process IDs and service/signing identifiers. No packet contents, passwords or process environments are collected. Saved files have owner-only permissions. Review a report before sharing it.

An unknown, blocked or ambiguous discovery is reported as such. An allow entry does not establish a forwarding API or permission from other network filters.

Release assets include SHA256SUMS for download integrity checks. The CLI is included inside the app at Contents/MacOS/screensharing-proxy-diagnose.
