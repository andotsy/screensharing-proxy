Screen Sharing Proxy

Diagnostic alpha · Apple silicon · macOS 14+

This first release automatically discovers a proxyd executable with a listed incoming-connection allowance and collects network diagnostics. The Screen Sharing relay and native GUI are still being developed. This version does not forward traffic or change the firewall.

Run automatic discovery

Open the included Terminal shortcut. Copy and paste the command below while this disk image is mounted. It creates a new folder in Downloads, copies the diagnostic tool, verifies its signature, removes quarantine from that copy if present, and writes a redacted report beside it. No Xcode or Python is needed to run the compiled tool.

(
set -eu
tool_dir=$(mktemp -d "$HOME/Downloads/ScreenSharingProxy-Diagnostics.XXXXXX")
tool="$tool_dir/screensharing-proxy-diagnose"
cp '/Volumes/Screen Sharing Proxy Diagnostics/screensharing-proxy-diagnose' "$tool"
/usr/bin/codesign --verify --strict "$tool"
/usr/bin/codesign --display --verbose=2 "$tool" 2>&1 | /usr/bin/grep -Fx 'Identifier=com.andotsy.screensharing-proxy.diagnose' >/dev/null
if /usr/bin/xattr -p com.apple.quarantine "$tool" >/dev/null 2>&1; then
    /usr/bin/xattr -d com.apple.quarantine "$tool"
fi
printf 'Tool and report folder: %s\n' "$tool_dir"
"$tool" discover --output "$tool_dir/proxyd-report.json"
)

An unresolved discovery exits with code 3 and still writes a report. It may mean no matching executable, an inaccessible or blocked candidate, an ambiguous match, or unknown firewall settings. An allow entry does not prove that the service supports forwarding or that every network filter permits it.

Collect session sockets

Start the failing High Performance Screen Sharing session, then run the copied tool with collect --remote REMOTE_IP --output viewer-report.json. Replace REMOTE_IP with the remote Mac’s numeric IPv4 or IPv6 address. Use --help for all options. The tool refuses to overwrite reports.

Report privacy and signing

Private addresses and non-system paths are replaced by tokens by default. Reports retain system executable paths, ports, process IDs and service/signing identifiers. They contain no packet payloads or process environments. Files are created with owner-only permissions. Review a report before sharing it.

This alpha is ad hoc signed and is not notarized. Release assets include SHA256SUMS for download integrity checks.
