Screen Sharing Rubyfier

Version 1.0.1 · Apple silicon

Adds our Ruby relay to a separate copy of Screen Sharing. Your original app stays untouched. This build accepts the tested Screen Sharing executable from macOS 26.7.1 (25G241). High Performance video, audio, and keyboard/mouse control have been verified on that build.

Create your app

  1. Drag Screen Sharing Rubyfier.app onto Applications.
  2. On the controlling Mac, open Rubyfier and click Create Rubyfied App…. Choose a writable folder, such as your user Applications folder.
  3. Open Screen Sharing Rubyfied.app. If the original viewer is open, the copy offers to quit it; this disconnects its viewer sessions. Allow Local Network access when macOS asks. If previously denied, enable Rubyfied in System Settings → Privacy & Security → Local Network.
  4. Enter the remote Mac’s real IPv4 address in the native connection window. Authenticate normally and choose High Performance when offered. Do not enter 127.0.0.1 or port 15900.
  5. Quit Rubyfied to stop its relay. A new attempt can restart a stopped relay, up to three times per minute. Quit and reopen before changing an active host.

The patcher bundles optool, the compiled library and relay scripts. No Xcode, command line tools, Python or gems need to be installed. An existing Rubyfied app is never overwritten. No network or sharing-service settings are changed.

Rubyfier can be closed after creation. Its console is scrollable, read-only and selectable; Copy All copies the log.

Reports and validation

Diagnostics → Collect Diagnostics collects a ZIP and opens a save dialog. Rubyfied writes private transport counters to ~/Library/Logs/Screen Sharing Rubyfied/latest-session.json.

Live High Performance video, audio, and keyboard/mouse control have been verified. Automated tests cover native sign-in, retry recovery and three bidirectional media channels. Sustained performance and receiving permission under the restricted viewer’s network rules remain unverified.

If macOS blocks the app

This build is ad hoc signed and not notarized. After installing it in Applications, open the included Terminal shortcut and paste the command below. It verifies the bundle identity and signature, removes quarantine only from that app, and opens it. Use it only for a download you trust. An ad hoc signature checks integrity, not publisher identity.

(
set -eu
app='/Applications/Screen Sharing Rubyfier.app'
test "$(/usr/libexec/PlistBuddy -c 'Print :CFBundleIdentifier' "$app/Contents/Info.plist")" = com.andotsy.screensharing-proxy
/usr/bin/codesign --verify --deep --strict "$app"
/usr/bin/codesign --display --verbose=2 "$app" 2>&1 | /usr/bin/grep -Fx 'Identifier=com.andotsy.screensharing-proxy' >/dev/null
/usr/bin/xattr -dr com.apple.quarantine "$app"
/usr/bin/open "$app"
)

Privacy and integrity

Shared diagnostics redact private addresses and non-system paths by default. Our reports exclude credentials, media keys and packet contents. Review reports before sharing them. The accompanying SHA256SUMS checks download integrity.
