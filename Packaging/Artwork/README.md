# Proxy icon artwork

`AppIcon.png` is the generated source artwork for the macOS app icon: two white
right-pointing arrows separated by a mint divider on a graphite tile. Transparent
padding is part of the artwork. `Packaging/app-icon.swift` packages this image
into the standard macOS icon sizes, and `iconutil` creates the bundled ICNS.

Created with image generation on 2026-10-17 from the user-supplied
`proxy-svgrepo-com.svg`, preserved here as `ProxyReference.svg`. The supplied SVG
identifies SVG Repo (https://www.svgrepo.com/) in its metadata. Its arrow/divider
arrangement is the reference for the new artwork; no claim is made that the
reference symbol was authored by this project.
