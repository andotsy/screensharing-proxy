# Screen Sharing Proxy v0.1.0-alpha.5

- Order the tabs **Proxy → Settings → Diagnostics**. Diagnostics remains selected
  on launch and fully usable; Proxy and Settings remain grayed out.
- Remove the extra icon, app-name and ALPHA header. Tabs sit directly below the
  native window title.
- Include the updated Icon Composer artwork from the repository, with native
  light, dark and tinted appearances and an ICNS fallback.

Download **ScreenSharingProxy-v0.1.0-alpha.5-macOS-arm64.dmg** and drag the app to
Applications. Requires Apple silicon and macOS 14+. No Xcode or Python is needed.

On the viewer Mac, keep the Screen Sharing connection attempt open, click
**Collect Diagnostics**, then choose where to save the ZIP.

Traffic forwarding remains unavailable. The app is ad hoc signed and not
notarized; use the included offline guide if macOS blocks launch. Verify the
download using SHA256SUMS.
