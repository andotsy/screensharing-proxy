# Screen Sharing Rubyfier 1.1.1

- Fixes High Performance disconnections when enabling Dynamic Resolution or
  resizing the remote display with SharpShare. Replacement streams now reuse
  the connected media socket instead of trying to bind an occupied port.
- Renames the patcher executable to `ScreenSharingRubyfier`.
- Shortens the tabless patcher window to 740×560 points.
- Keeps the Copy All checkmark inside the button. The button expands briefly
  while its right-edge padding stays fixed, with no reserved space when idle.
- Adds CI coverage for repeated native socket handoffs, queued-packet delivery,
  unrelated port conflicts, and socket cleanup.

**Create a new Rubyfied app with this patcher to receive the resize fix.**
Updating the patcher does not update an existing generated viewer.

Dynamic Resolution and SharpShare resizing were confirmed live on macOS 26.7.1
(25G241), with Screen Sharing 764.2 on Apple silicon. Other macOS builds are
allowed but remain unverified. Sustained performance and operation where the
firewall actually blocks Screen Sharing remain unverified.

The DMG is built and verified by GitHub Actions. It includes the Applications
and Terminal shortcuts and the offline HTML guide. The app is ad-hoc signed,
not notarized; `SHA256SUMS` is provided with the download.
