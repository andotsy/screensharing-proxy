# Screen Sharing Proxy v0.1.0-alpha.3

This diagnostic update collects the evidence needed after researching High
Performance Screen Sharing's media services. It still does not relay traffic.

Download **ScreenSharingProxy-v0.1.0-alpha.3-macOS-arm64.dmg** and drag the app to
Applications. Requires Apple silicon and macOS 14+. The native app, CLI and
offline installation guide are included. No Python or Xcode installation is needed.

Changes from alpha 2:

- Inspect the Screen Sharing client, `screensharingd`, `ScreensharingAgent` and
  `avconferenced` separately from allowed-`proxyd` discovery. Retain relevant
  processes even when they have no visible sockets.
- Record executable and enclosing-bundle firewall queries separately, plus
  signing identity and the socket-delegation entitlement where readable.
- Include TCP 5900 / UDP 5900–5902 port hints, visible local `hostSettings.portBase`,
  and loopback/wildcard/non-loopback bindings. Unknown evidence stays unknown;
  a local preference is not the remote host's or the active session's UDP base.
- Capture before and during a connection attempt, then export both in one JSON
  file with consistent redaction. Cancellation preserves completed captures.
- Single-report schema is now 2. The paired app export has its own schema 1
  envelope. CLI `--phase baseline|duringSession|snapshot` labels single reports;
  only app pairs share their redaction scope.

On the **viewer Mac with the blocked service**, enter the remote IP if known.
In **Diagnostics**, choose **Capture Baseline** before connecting. After it
finishes, start High Performance Screen Sharing and choose **Capture During
Session** while the attempt is starting or failing. Keep the attempt open, then
**Save Report…**. There is no need to install a companion on the remote Mac for
this collection.

Reports redact private addresses and paths by default. No packet capture,
credentials, process arguments or environments are exported. Collection changes
no firewall rule and requests no administrator access. Incomplete visibility,
socket delegation and other filters mean these reports cannot prove the cause of
a drop or that a relay will work. Live affected-Mac testing remains pending.

The app is ad hoc signed and not notarized. The included offline guide explains
installation and the app-specific launch command. Verify the DMG using the
published `SHA256SUMS`; published alpha 1/2 assets remain unchanged.
