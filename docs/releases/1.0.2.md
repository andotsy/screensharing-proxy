# Screen Sharing Rubyfier 1.0.2

- Creates Rubyfied from any installed Screen Sharing build instead of refusing
  builds other than the tested executable.
- Notes in the console when the installed executable differs from the tested
  build, then continues.
- Still detects a system executable that changes while the copy is created.

Tested only with the Screen Sharing 764.2 executable from macOS 26.7.1 (25G241)
on Apple silicon; other builds are untested. Existing Rubyfied viewers from 1.0.0
or 1.0.1 do not need to be recreated.

The DMG is built and verified by GitHub Actions. It is ad-hoc signed, not
notarized, and includes an offline installation guide and `SHA256SUMS`.
