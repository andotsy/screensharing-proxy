# Screen Sharing Proxy v0.1.0-alpha.2

This release adds the native macOS app missing from the first diagnostic alpha.
Download **ScreenSharingProxy-v0.1.0-alpha.2-macOS-arm64.dmg**, open it and drag
**ScreenSharingProxy.app** to **Applications**.

- Automatically discovers an explicitly allowed `proxyd` on launch, without a path field.
- Native Connection, General and Diagnostics panes, a menu bar menu and original relay icon.
- Collect, cancel, copy and save diagnostics without Terminal. Reports are redacted
  by default and saved with owner-only permissions.
- Optional Dock visibility and launch at login. Neither firewall nor display settings are changed.
- Includes the diagnostic CLI inside the app and an offline installation guide.

**This alpha does not forward Screen Sharing traffic.** The system service's
forwarding interface and High Performance transport still need verification on
the viewer Mac. A discovered allow entry alone does not establish relay support.

Requires Apple silicon and macOS 14+. The app is ad hoc signed and not notarized;
follow the included README if macOS blocks it. No Xcode/Python installation is needed.
Verify the downloaded DMG with the accompanying `SHA256SUMS`.

The release workflow builds and tests on macOS, checks bundle resources and
signatures, opens the native window, performs automatic discovery/report export,
checks the offline launch instructions, and verifies uploaded asset checksums
before publication. These checks do not establish live Screen Sharing forwarding.
