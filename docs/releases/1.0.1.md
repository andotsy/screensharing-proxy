# Screen Sharing Rubyfier 1.0.1

- Fixes the extra right-side space on **Copy All**.
- Keeps the button and text in place while its trailing confirmation checkmark appears.
- Retains the pressed-state feedback and two-second copied confirmation.

Requires the tested Screen Sharing 764.2 executable from macOS 26.7.1 (25G241)
on Apple silicon. This patch updates the Rubyfier interface; existing Rubyfied
viewers from 1.0.0 do not need to be recreated for this UI fix.

The DMG is built and verified by GitHub Actions. It is ad-hoc signed, not
notarized, and includes an offline installation guide and `SHA256SUMS`.
