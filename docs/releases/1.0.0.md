# Screen Sharing Rubyfier 1.0.0

First stable release of Screen Sharing Rubyfier.

- Creates a separate Rubyfied copy of Apple's Screen Sharing app.
- Working High Performance video, audio, and keyboard/mouse control, verified live.
- Ruby owns external TCP/UDP sockets; Apple's native decoder and image queue run
  inside the copied viewer.
- Recovers from stopped relay attempts and retains bounded failure diagnostics.
- Preserves localized app names and provides a selectable console with Copy All.
- Runs without administrator access or network-interface changes.

## Compatibility

Apple silicon with the tested Screen Sharing 764.2 executable from macOS
26.7.1 (25G241). Other native executable builds are refused. The patcher bundles
its tools and uses system Ruby; Xcode, Python and gems are not required.

Open Rubyfier, create a **fresh** Rubyfied app, then enter the sharing Mac's real
IPv4 address and choose High Performance. Allow Local Network access when asked.
Updating Rubyfier alone does not update an already-created viewer.

The DMG is built and checked by GitHub Actions and includes an offline guide.
This release is ad-hoc signed, not notarized. `SHA256SUMS` verifies the download.
The restricted viewer's network rules, other macOS builds and sustained
performance have not yet been validated. Existing prereleases are preserved.
