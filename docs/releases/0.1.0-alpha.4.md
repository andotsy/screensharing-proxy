# Screen Sharing Proxy v0.1.0-alpha.4

Screen Sharing Proxy opens on **Diagnostics**, with the future **Proxy** and
**Settings** tabs visible but grayed out. Click **Collect Diagnostics**, then
choose where to save the ZIP.
Send that ZIP to the person helping investigate the Screen Sharing connection.

Download **ScreenSharingProxy-v0.1.0-alpha.4-macOS-arm64.dmg** and drag the app to
Applications. Requires Apple silicon and macOS 14+. No Xcode or Python is needed.
Run it on the **viewer Mac with the blocked service**, keeping the Screen Sharing
connection attempt open while collection runs.

- Keep the full Screen Sharing Proxy app shell, with Diagnostics selected and
  usable, and Proxy/Settings disabled. No manual before/during captures, remote
  IP entry, active Dock/startup toggles or menu bar utility. Closing the window quits.
- Automatic Save dialog after collecting ten snapshots. The ZIP contains the
  complete structured diagnostics and a short README, with private addresses
  and paths hidden. Cancelled/failed saves can be retried without recollecting.
- Preserve OS, firewall, service, signing, entitlement and socket evidence.
  Include unattributed connected UDP sockets without requiring a remote IP.
- Report allowed/blocked Python and Ruby firewall targets separately, including
  versioned runtimes and Python.app bundles. No proxyd does not mean no allowed runtime.
- New graphite icon with white arrows and a mint divider.
- Styled DMG with fixed app/Applications positions, an installation arrow,
  Retina background, bundle-derived version label, offline guide and Terminal.
- Remove this app's old launch-at-login registration when upgrading.

Only the app's diagnostic features are enabled; traffic forwarding is not implemented. It makes
no firewall or display changes. The app is ad hoc signed and not notarized;
follow the included offline guide if macOS blocks launch. Verify the download
using SHA256SUMS. Published older releases are unchanged.
