# Screen Sharing Rubyfier 1.1.0

- Rubyfier now opens straight to the patcher. The Diagnostics tab and the bundled
  `screensharing-proxy-diagnose` command-line tool are removed.
- When an address isn't IPv4, Rubyfied now explains that it only connects to
  another Mac by its IPv4 address.
- Shorter, plainer README and installation guide.

Tested only with the Screen Sharing 764.2 executable from macOS 26.7.1 (25G241)
on Apple silicon; other builds are untested. Existing Rubyfied copies keep
working; create a new copy to get the clearer connection message.

Known issue: turning on Dynamic Resolution during a High Performance session
corrupts the stream and the connection closes. Leave it off for now.

The DMG is built and verified by GitHub Actions. It is ad-hoc signed, not
notarized, and includes an offline installation guide and `SHA256SUMS`.
