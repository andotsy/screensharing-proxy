# Screen Sharing Proxy 0.1.0-alpha.1 — diagnostic alpha

This first prerelease supplies a compiled macOS diagnostic tool. It automatically
discovers `proxyd` candidates and their listed incoming-connection rules, and
collects redacted process/socket evidence for the High Performance Screen Sharing
investigation.

**The Screen Sharing relay and native GUI are not implemented in this version.**
It does not forward traffic, change firewall rules, or change display settings.

Download the **macOS arm64 DMG**, open its offline `README.html`, and use the
included Terminal shortcut to run discovery. No Xcode or Python is needed for
the compiled binary. Requires Apple silicon and macOS 14 or later. The tool is
ad hoc signed and not notarized; the offline guide explains how to run the copy.

Included foundations: bounded subprocess execution and cancellation, process
group cleanup, structured firewall/socket discovery, default report redaction,
versioned backend event framing and session-generation handling.

The release workflow runs the Swift tests, checks the compiled tool on macOS,
verifies the DMG's contents and signature, and checks uploaded asset checksums
before publishing. Synthetic transport tests do not establish a working High
Performance relay. That experiment remains pending on the actual viewer Mac.
